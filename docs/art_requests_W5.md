## Watchers (Graphics/Characters/Followers)
The ten faction watchers use the base species' follower sprite at low
opacity (SUDOWOODO, MISDREAVUS_fly, VENOMOTH_fly, RATICATE, PORYGON,
FURRET, HAUNTER_fly, LEDYBA_fly, MURKROW, GENGAR). A tinted or
"half-seen" version of each would sell them as spies.
