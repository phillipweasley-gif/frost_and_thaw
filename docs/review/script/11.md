# Part 11 · Chapter 11: The Frost Saint Walks (as played)

The as-played shooting script for Chapter 11, from the last box of Act II to `ch11_done` and the griffon-roost goal.
Source: `parts/11.txt` (New Journey mode, player "[Name]"), with every branch the test didn't take written from
`037_Chapter11.rb`, `047c_WhiteVault.rb` and `047d_FixRound.rb`. Staging comes from the log's `[stage]` lines and,
where marked "(code)", from the scene code and the built maps (`tools/build_ch6.rb`, `build_ch6b.rb`, `build_act3.rb`,
`build_w4.rb`; checked against the built `Map2053/2054/2061.rxdata`).

One thing to know before reading: from the last choice of Act II to the first battle here there are about 66 boxes
with no input, and the Hearth, the Shrine and Three Hearts run as one unbroken cutscene. The goal "The Shrine of the
Twinned Dragons. Now." is set and immediately consumed by the next autorun, so the player never sees it.
